## 4. API共通規約（設計上の参照・実装状況は要確認）

### 4.1 バージョンと形式

- REST/JSON、URI `v1`、UTF-8。API日付時刻は UTC の ISO8601（`Z`）。UI表示は Asia/Tokyo。
- `camelCase` で統一。共通ヘッダー `X-Firebase-AppCheck`、`X-Request-Id`。認証済みAPIは `Authorization: Bearer <Firebase ID token>`。認証前の `POST /auth/register` のみ認証不要（App Check・レート制限は必須）。副作用POSTの冪等キーは正規名 **`Idempotency-Key`**。
- PUT/PATCH は `If-Match` / `ETag` または `revision` 検証で競合を防ぐ。
- **患者IDはURLに置かず、検証済みトークンから解決する**（`services/api/src/routes/me.ts` が参照）。
- 正常/異常レスポンスに医療情報を不用意にエコーしない。これらは設計上のルールであり、各 API への適用は未照合。

### 4.2 標準エラー

> この節番号は `services/api/src/lib/errors.ts` のコメントが参照するため維持する（§0 の3）。

```json
{
  "error": {
    "code": "VALIDATION_FAILED",
    "message": "入力内容を確認してください。",
    "fieldErrors": [{"field": "birthDate", "message": "正しい日付を選んでください。"}],
    "requestId": "req_01J...",
    "retryable": false
  }
}
```

| HTTP | code | 発生条件 | UI |
|---:|---|---|---|
| 400 | VALIDATION_FAILED | 形式/長さ/Enum不正、必須checkbox=false | 入力箇所へ案内 |
| 401 | UNAUTHENTICATED | Token不正/期限 | 再ログイン |
| 403 | FORBIDDEN | 別テナント/不同意/退会中 | 汎用権限エラー |
| 404 | NOT_FOUND | 存在しない/閲覧権限なし | 資源不明を統一 |
| 409 | REGISTRATION_CONFLICT | 登録キー競合・既存メール競合 | 無断紐付けはしない |
| 409 | REVISION_CONFLICT | 他端末編集 | 再読み込み・変更確認 |
| 409 | ALREADY_DELIVERED | 同一配送命令の競合 | 同一結果を表示 |
| 412 | PRECONDITION_FAILED | 同意/確定/施設審査の不足 | 条件を案内 |
| 413 | FILE_TOO_LARGE | アップロード上限超過 | 画像縮小案内 |
| 422 | MODEL_SCHEMA_REJECTED | AI応答の検証失敗 | 固定質問へ切替 |
| 429 | RATE_LIMITED | 呼出超過 | Retry-Afterを表示 |
| 503 | UPSTREAM_UNAVAILABLE | OCR/LLM/Places故障 | 再試行か代替手段 |

- デモでは 503 を「架空のエラー演出」として実サービス故障と混同しない。模擬であっても成功を装ってエラーを隠さない。
